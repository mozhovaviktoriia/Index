Уведомления в Telegram-группу

Сайт отправляет подписанные уведомления в группу через Cloudflare Worker. Входящий Telegram webhook и привязка личных аккаунтов не используются.

Если выключено, новые уведомления и сообщение о жеребьёвке будут без имён и ников. Уже отправленные сообщения не изменятся.

Кличка отдельно генерируется для каждой переписки при входе в неё. Если участник ещё не открывал эту переписку, уведомление будет общим. При включённом показе имён клички не используются.
